# LED Blinking Project

This project demonstrates how to blink LEDs using a microcontroller. The example uses built-in and external LEDs connected to specified pins.

## Requirements
- Microcontroller (e.g., STM32, Arduino)
- LEDs
- Resistors (if needed)
- Power source

## Pin Configuration

| LED Name     | Pin |
|-------------|-----|
| LED_BUILTIN | PC13 |
| LED1        | PF0 |
| LED2        | PF1 |
